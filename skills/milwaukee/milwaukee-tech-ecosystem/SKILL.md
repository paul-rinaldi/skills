# Milwaukee Tech Ecosystem

A directory of the Greater Milwaukee tech and startup ecosystem, adapted from the MKE Tech Hub Coalition's "#mketech Resource Guide." The listings are in `references/`. Load only the file the question needs.

| File | Covers |
|---|---|
| `references/founders.md` | Investors, incubators and accelerators, founder communities and events, coworking |
| `references/learning-talent.md` | AI workshops and courses, student programs, upskilling, continuing education, research institutes |
| `references/networking.md` | Professional and affinity orgs, marketing meetups, tech orgs, podcasts, volunteer nonprofits, local tech service firms |
| `references/mke-tech-hub.md` | MKE Tech Hub Coalition's own programs (FOR-M, FUSE, Catalyze, Synapse, AI Community) and how to get involved |

## How to answer
1. **Match the need to a category, then recommend 2 to 5 specific orgs** with a one-line reason for each. Don't dump the whole list.
2. **Verify before relying on anything time-sensitive.** This list is a snapshot. Programs get renamed, cohorts close, and events move. Search the web for current dates, deadlines, and whether an org is still active, and say when something couldn't be confirmed.
3. **Never state an event date from these files.** The files deliberately record only how often events happen. Look up the next date.
4. **Link to the org's site.** For personal contacts, point to the org's contact page rather than an individual's email.

## Pairing with other skills
- **problem-worth-solving** (market and customer lenses): suggest local orgs whose members are the target customer, so Paul can line up interviews.
- **solution-options** (who pays): investors in `founders.md`, plus workforce and nonprofit funders in `networking.md` and `learning-talent.md`.
- **mvp-experiment-designer**: coworking spaces and founder events for testing an idea in person (concierge or Wizard of Oz experiments).
- **Workforce or disability-employment ideas:** Employ Milwaukee, i.c.stars, and the Urban League of Greater Milwaukee are workforce-development orgs worth approaching as partners or customers.
